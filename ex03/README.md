# Discovery Web Piscine

## Project Overview

This project introduces the fundamentals of Linux command-line usage, Git version control, and GitHub collaboration. It provides practical experience with file management, shell scripting, repositories, commits, branches, and remote repositories.

## Exercise 00 — Linux File Structure

Exercise 00 focuses on navigating the Linux filesystem and creating a structured workspace using basic terminal commands.

The exercise demonstrates:

* Navigating directories with `pwd` and `cd`
* Listing files and directories with `ls`
* Creating directories with `mkdir`
* Creating nested directory structures
* Recording the resulting structure in `tree_structure.txt`

## Exercise 01 — File Management and Shell Script

Exercise 01 focuses on basic file operations and shell scripting.

The exercise demonstrates:

* Creating files with `touch`
* Writing and appending text with `echo`
* Displaying file contents with `cat`
* Copying files with `cp`
* Renaming files with `mv`
* Removing temporary files with `rm`
* Automating file operations with a shell script

## Exercise 02 — Git and GitHub

Exercise 02 introduces Git version control and remote GitHub repositories.

The exercise demonstrates:

* Configuring Git user information
* Initializing a Git repository
* Tracking files with `git add`
* Creating commits with `git commit`
* Checking repository status with `git status`
* Connecting a local repository to GitHub
* Pushing changes to the `main` branch

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes and allows developers to work safely on projects over time. Developers can create commits to record meaningful changes, review the history of a project, and return to earlier versions when necessary.

Git also supports collaboration by allowing multiple developers to work on the same project while keeping track of their changes. When Git is connected to GitHub, repositories can be stored remotely, shared with others, and updated through a clear workflow.

Using Git encourages organized development because changes can be grouped into meaningful commits with descriptive messages.
